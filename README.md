# Zig_Zag_Rush
A fast-paced 3D Endless Runner game developed in Unity. The game features a procedurally generated, winding path where players must dodge obstacles, jump over rolling drums, slide under caves, and collect coins to achieve the highest score possible.

🎮 Features
Dynamic Zigzag Path: A procedurally generating track that curves left and right, requiring quick reflexes to stay on the road.

Lane-Switching Physics: Custom character controller logic for smooth, responsive lane changes, jumping, and sliding.

Multiple Obstacle Types:

Tall and wide blocks to dodge.

Low hurdles and rolling drums to jump over.

Stone caves that require the player to slide underneath.

Power-Ups & Collectibles: Spinning gold coins, with U-shaped floating bundles, and functionality for power-ups (Shield & Magnet).

Game Feel (Juice): Includes camera shake on impact, particle effects (dust) on jumps/slides, and custom sound effects for jumping, swiping, and crashing.

Score & UI System: Real-time score tracking and coin collection UI.

Endless Replayability: Difficulty scales over time, increasing the game speed and obstacle spawn rate.

🛠️ Built With
Unity Engine (3D)

C# for all gameplay logic, object pooling, and procedural generation.

TextMeshPro for UI elements.

🚀 How to Play
Clone the repository.

Open the project in Unity (Version 2021.3 or newer recommended).

Open the Main scene.

Press Play!

Controls:

W / Up Arrow / Space: Jump (Hold for a higher jump)

S / Down Arrow: Slide

A / D or Left / Right Arrows: Change lanes.
